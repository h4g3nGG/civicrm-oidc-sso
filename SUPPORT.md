# Support

This project is pre-release software and is not approved for production use.

- Use a GitHub bug report for reproducible defects that contain no sensitive
  information.
- Use a feature request for provider-neutral enhancements.
- Send suspected vulnerabilities privately to
  `civicrm-oidc-sso@whatchamacallit.xyz` and follow [SECURITY.md](SECURITY.md).

Do not publish tokens, credentials, claims, personal data, internal hostnames
or exploit details. There is currently no guaranteed response time or paid
support offering.
